LOGIC QUEST SYSTEM ● ONLINE

O sistema precisa guardar algumas informações.

Essas informações poderão ser acessada posteriormente.

CONCEITO

VARIÁVEL

Uma variável é um espaço na memória utilizado para armazenar uma informação. Podemos comparar uma variável com uma caixinha com etiqueta, onde você guarda a informação para usar depois. Essa variável pode ser acessada/reutilizada ou atualizada quantas vezes for preciso.

EXEMPLO 
idade <- 20

A variável idade recebe o valor 20.

EXEMPLO 2 
idade

A variável idade pode ser usada em outras partes do codigo ou atualizada. 

idade <- 58
Agora a variável idade tem um inteiro 58.
